🕰️ Vintage Neon Clock

A retro-style digital clock with a buzzing neon aesthetic, built using HTML, CSS, and JavaScript.





🛠️ Built With

HTML5: Structure and Layout.

CSS3: Custom Neon Glow (text-shadow, box-shadow), Flicker Animations (@keyframes), and Fonts.

JavaScript: Real-time logic (Date object) to fetch and format the current time.

✨ Features

1. Real-Time Updates: Accurate to the second, updating every 1000ms.

2. Neon Aesthetics: CSS text-shadows create a realistic glowing gas effect.

3. Flicker Animation: Simulates a vintage/broken neon sign buzz.

4. Responsive: Centers perfectly on the screen using Flexbox.

🏃‍♂️ How to Run locally

1.Clone this repository.

2.Open index.html in your browser.

3.That's it! No installation required.
